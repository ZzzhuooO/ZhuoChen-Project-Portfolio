# 自动行驶小车设计与测试

## 项目简介
在大学工程设计课程中，与小组完成能够沿指定路线行驶的模型小车。项目围绕设计、制作、测试和调整展开，以完成路线任务并改进运行表现为目标。

## 我的贡献
- 担任小组组长，推动任务分工、测试记录和结果讨论。
- 使用 MATLAB 对小车运行数据进行建模与分析，评估设计表现。
- 根据测试中发现的问题与小组调整方案，并通过再次测试验证改动效果。

## 技术栈
MATLAB、基础工程建模、实验测试、迭代设计与团队协作。

## 结果或演示
团队完成模型小车制作与指定路线测试，并通过迭代使其成功完成路线任务。现有简历未提供可复核的用时或排名，因此不写具体提升百分比或竞赛名次。照片、测试记录或可公开的模型文件待补充。
