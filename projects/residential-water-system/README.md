# 供水基础设施概念设计与参数分析

## 项目简介
针对课程中的供水工程场景，分析用水需求、储水容量、流量以及管网和设备参数，为住宅供水系统的概念方案提供计算依据。最终形成团队设计方案和 MATLAB 参数分析结果。

## 我的贡献
- 担任小组组长，拆解设计要求、推动分工与方案讨论，并汇总分析结果。
- 使用 MATLAB 对用水量、处理流量、管道流速、雷诺数、摩擦及局部水头损失等参数进行计算和比较。
- 将模型结果与实际设计约束结合，支持方案选择、讨论和技术表达。

## 技术栈
MATLAB、工程参数建模、流体力学计算、方案比较与团队协作。

## 结果或演示
完成供水系统概念方案及相应的参数分析，形成从需求估算、模型计算到方案比较的完整工作链；分析结果为团队讨论管网和设备配置提供了依据。
