# Codex 辅助内容制作与可复用工作流

## 项目简介
将 AI 工具用于真实的内容和项目任务，而非只进行一次性问答。围绕课程资料整理、Blender 书房设计、单词本制作及账号数据复盘，形成需求拆解、工具协作、迭代和验收的工作方法。

## 我的贡献
- 使用 Codex 工作台推进不同类型的个人项目，明确目标与交付格式，检查输出并依据反馈反复修改。
- 搭建自定义 Skills、接入插件，把资料提取、内容生成和文档整理等多步骤任务沉淀为可复用流程。
- 在小红书账号运营中导出笔记数据并借助 Codex 比较内容表现，再将分析结论用于下一轮选题和呈现调整。

## 技术栈
Codex、Skills、插件集成、Blender、表格数据分析及文档制作；方法包括任务分解、提示词迭代、人工核验与流程复用。

## 结果或演示
已完成书房设计方案、单词本和结构化双语学习资料，并将账号复盘用于内容迭代。当前项目资料目录中尚无这些成品的可公开截图、文件或独立仓库，因此本页不提供未经核实的演示链接，也不把工具使用量当作业务成果。

## 如何运行
不同 Skills 和插件依赖各自的运行环境，当前未整理为可复制安装的软件包。本项目以方法和交付物说明为主；待补充可公开的 Skill 文件、项目截图或演示后再提供逐步配置方法。
