# 可露丽小厨房｜六步制作交互玩具

一个用 Python 和 Tkinter 制作的桌面小玩具。把可露丽从准备面糊到烘烤冷却的过程拆成六步，通过投料、搅拌、倾倒和温度控制，让制作过程变成可以逐步操作的动画。

## 项目起点

最初的想法是用温度旋钮观察可露丽的外观与切面变化，随后扩展为完整制作流程。界面采用深色背景、玻璃器皿和铜制模具，烘烤阶段保留外观与切面并排展示。

## 我的工作与实现方式

- 整理配方和制作顺序，确定六步流程、每模面糊用量与冷却时间。
- 设计各阶段的操作和视觉反馈：香草保留在奶锅里，蛋糖加入空碗，容器统一向左倾斜，倾倒后液面减少或容器变空。
- 逐轮提出修改要求，细化七分满铜模、温度边界、字幕内容等表现。
- 使用 AI 辅助编写和调整 Python/Tkinter 代码；我负责需求、配方整理、交互设计与迭代反馈。

## 六步流程

| 步骤 | 操作与动画 |
| --- | --- |
| 1. 香草浸香 | 香草加入玻璃奶锅，牛奶与黄油煮沸 10 秒，再关火浸香 15 分钟；香草继续留在锅里 |
| 2. 混合蛋糊 | 从空玻璃碗开始，倒入全蛋、蛋黄和糖，打散后加入过筛面粉拌匀 |
| 3. 合并面糊 | 微温香草牛奶倒入蛋糊，放凉后加入朗姆酒；用容器左倾及液面变化表示倾倒 |
| 4. 冷藏静置 | 贴面覆盖保鲜膜，演示 48 小时冷藏 |
| 5. 装入铜模 | 回拌、过筛后逐个装入六个铜模，每模 80g，约七分满；量杯余量随之减少 |
| 6. 烘烤与冷却 | 预热、烘烤 50 分钟、观察颜色，可降温或追加 10 分钟，最后冷却 45 分钟 |

首次养模、烘烤前涂层和详细脱模操作未纳入本版本。长时间等待压缩为几秒演示。

### 温度与字幕

烘烤阶段可以在 160–240°C 之间调节设定温度，也可以点击“降温 10°C”。

- **低于 200°C**：保留已有颜色；该段烘烤结束后显示“低于200°C......没有上色！”。
- **200–220°C（含边界）**：按累计加热量改变上色程度，不显示上述异常温度字幕。
- **超过 220°C**：外观和切面整体显示焦糖棕；该段烘烤结束后显示“超过220°C！烤糊啦！”。

字幕按照每段烘烤结束时的设定温度生成。调温影响后续烘烤；停止烘烤后单独拖动滑杆不会重新生成字幕。

这些规则用于交互演示，不是实际烤箱的温度预测或食物检测结果。

## 配方记录

| 材料 | 用量 |
| --- | --- |
| 香草荚 | 2 根 |
| 牛奶 | 276g |
| 黄油 | 28g |
| 全蛋 | 56g |
| 蛋黄 | 22g |
| 糖 | 138g |
| 低筋面粉 | 56g |
| 朗姆酒 | 22g |

未计香草荚的面糊理论总量为 598g。六模分装 480g，理论余量 118g，未扣除加热、过筛和挂壁损耗。

## 如何运行

需要包含 Tkinter 的 Python 3，无需安装第三方 Python 库。

1. 下载本仓库并解压，进入 `projects/canele-kitchen` 文件夹。
2. Windows 可双击 `打开可露丽.cmd`，或在该文件夹打开终端执行：

   ```powershell
   py -3 canele_temperature_toy.py
   ```

   其他系统可使用已安装且带有 Tkinter 的 Python：

   ```sh
   python3 canele_temperature_toy.py
   ```

3. 点击左下角按钮完成当前操作，再点“下一步”。已经完成的步骤可通过顶部导航返回查看；“重新制作”恢复初始状态。

直接预览第六步：

```powershell
py -3 canele_temperature_toy.py --preview-step 6
```

`--preview-step` 支持 1–6。若提示找不到 `tkinter`，需要为当前 Python 安装 Tk 支持。

## 当前范围

这是桌面源码版本，需要本地 Python 环境。界面中的切面、颜色和时间变化均为简化示意。程序无需登录，不调用外部服务；关闭程序后不会保存本次制作进度。
