# 卫星影像配准与正射校正

## 项目简介
在Imaging the Environment小组项目中，研究如何将原始卫星影像转化为可用于空间测量的影像。小组围绕控制点配准、数字高程模型（DEM）生成、正射校正和独立检查点验证完成方法设计与报告。

## 我的贡献
- 负责报告中任务 1（影像配准）与任务 3（正射校正）的方法部分。
- 撰写关于配准 RMSE 的影响因素、地面控制点（GCP）的作用及空间分布的讨论。
- 参与将影像处理步骤与精度检验逻辑整理为可交流的技术说明。这里仅列个人分工，不把团队全部影像处理成果写成个人独立完成。

## 技术栈
ENVI、遥感影像处理、GCP 配准、DEM、正射校正、RMSE 与独立检查点验证。

## 结果或演示
团队形成墨尔本区域的配准影像、DEM 与正射影像，并通过检查点及地籍边界叠加讨论位置精度。报告亦识别了部分影像/DEM 结果的异常和局部叠加误差，因此不宣称所有输出均达到统一精度。原始卫星影像及含队友信息的完整课程报告不在此仓库公开。

## 如何运行
完整复现需要 ENVI、原始卫星影像、控制点和相应许可；这些课程数据未随仓库分发。本页是个人工作与团队成果摘要，无可直接运行的软件包。
