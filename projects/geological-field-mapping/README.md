# 野外地质填图与构造数据整理

## 项目简介
在澳大利亚阿德莱德周边的偏远、构造复杂地区开展团队野外调查，将露头观察和产状测量整合为可核对的地质图与剖面。项目目标是用现场证据约束岩性、地层和构造关系。

## 我的贡献
- 在约一周的野外作业中记录岩性、地层接触和主要构造特征，采集并整理 60 余组构造测量数据。
- 使用 Avenza Maps 完成导航、定位与现场资料记录，使用 ArcGIS 整理和可视化空间信息。
- 参与 6 张工作图的汇编与交叉核对，并综合填图、测量和地层对比结果绘制 2 条地质剖面。
- 与组员讨论观察差异和解释结果，遵守现场安全与环境管理要求。

## 技术栈
野外地质填图、产状测量、地层对比、Avenza Maps、ArcGIS、地质图与剖面编制。

## 结果或演示
形成最终地质图、2 条地质剖面和 6 张工作图；现场数据保持可追溯。为避免直接公开完整课程材料，本仓库暂以方法和结果摘要展示，图件将在确认可分享范围后补充。

## 如何运行
这是实地调查项目，无需安装。复核流程为核对观测点与产状记录、检查工作图之间的接边关系，再对照最终地质图和剖面解释。
