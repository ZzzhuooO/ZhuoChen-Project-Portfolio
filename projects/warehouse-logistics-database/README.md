# 仓储与物流业务数据库设计

## 项目简介
将客户、商品、库存、订单和运输等业务信息拆解为关系型数据模型，解决多类实体及其关联难以在单张表中清晰表达的问题。最终形成物理实体关系图和数据库设计方案。

## 我的贡献
- 独立梳理客户、仓库库存、商品分类、订单明细、发货及车辆等实体之间的关系。
- 设计字段类型、主键与外键，并使用关联表表达商品分类、员工认证以及发货与订单明细等多对多关系。
- 使用 MySQL Workbench 绘制并核对物理 ER 图，整理模型结构与业务逻辑。

## 技术栈
SQL、MySQL Workbench、关系数据库建模、ER Diagram、主外键及关联表设计。

## 结果或演示
完成覆盖客户、商品、仓储、订单、运输和员工认证等业务环节的物理 ER 模型，明确实体关系、字段类型与主外键约束。该成果聚焦数据库结构设计，尚未部署为业务系统。
